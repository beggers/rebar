## Regression explanation

All listed regressions are retained. The Python backtracker spends most of its time creating Python states and scanning one position at a time. The Rust engine repeatedly crosses the Python/Rust boundary and creates eager continuation state, which dominates these short calls. The native C engine has 0 large slowdown(s): none. Its remaining Unicode-word case repeatedly checks Unicode word boundaries and character categories; this path cannot use the simpler one-pass token scan. Long misses amplify scanning, while find-all, iteration, splitting, and replacement amplify per-match work. The raw memory observations and every case remain available for inspection.
