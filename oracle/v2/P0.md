# Expanded P0 compatibility matrix v2

This oracle keeps every v1.1 obligation and adds documented public behavior that a broader audit found was missing. The baseline remains the latest stable CPython, **3.14.6**, with Unicode 16.0.0 and the `C` locale. The parent v1.1 fixture is immutable and its SHA-256 is `983885ee6411fd806edf3d72efbcc989f9b9f7775a6d127dc7c865673eeb0fed`.

The expanded suite has **8,244 cases** and **45/45 mapped obligations**. It retains all 2,048 v1.1 cases, adds 52 directed public-contract cases, and adds 4,096 seeded text plus 2,048 seeded bytes differential cases with longer subjects and deeper combinations of captures, backreferences, conditionals, lookarounds, atomics, possessive/lazy repeats, boundaries, and scoped flags. Seeds and stable case IDs are committed; the baseline is generated twice and must agree byte-for-byte.

New obligations:

| Obligation | Coverage |
| --- | --- |
| `API-GENERIC` | documented `Pattern[str]`, `Pattern[bytes]`, `Match[str]`, and `Match[bytes]` aliases |
| `API-BYTESLIKE` | `bytearray`/`memoryview` subjects, bytes-like replacements, and `escape` behavior |
| `API-REPRESENTATION` | observable `repr` for text/bytes patterns and short/long matches |
| `API-MATCH-COPY` | documented atomic `copy`/`deepcopy` and exact pickle rejection for matches |
| `E-DEPRECATION` | CPython 3.13+ positional `maxsplit`/`count` deprecation warnings |
| `S-LOOKBEHIND-REF` | documented fixed-width numbered/named lookbehind references and variable-width rejection |
| `S-DEEP-FUZZ` | larger deterministic syntax/API combinations, including the 3.14 empty-input `\B` behavior |

The original 38 obligations and two named private waivers remain in [v1/P0.md](../v1/P0.md). No public behavior is waived. Ambiguous-set warnings now cover nested sets, intersection, union, symmetric difference, and difference forms. Inline-flag errors cover incompatible `a`/`u`/`L`, forbidden removal, and conflicting on/off flags. Final-newline and windowed `$` cases are explicit.

The authoritative references are the [CPython 3.14 `re` documentation](https://docs.python.org/3.14/library/re.html) and the [Python source-release index](https://www.python.org/downloads/source/). The latter was checked on 2026-07-21 and lists 3.14.6 as the latest stable release.

Reproduce a failure without changing the denominator:

```sh
PY=/tmp/rebar-cpython/cpython-3.14.6-linux-x86_64-gnu/bin/python3.14
PYTHONPATH=. "$PY" tools/oracle_v2.py verify --module rebar --case v2.lookbehind.number-ref
```
