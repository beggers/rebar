# P0 compatibility matrix v1

P0 is the complete public `re` surface and the documented regular-expression syntax on the pinned CPython. A candidate passes only when every obligation below is exercised by the frozen suite and all observable results agree. Private implementation details are excluded by the two named waivers at the end; there are no public waivers.

| Obligation | Coverage |
| --- | --- |
| `API-EXPORTS` | exact `__all__`, exported classes, aliases, and `error is PatternError` |
| `API-FLAGS` | `RegexFlag`, all long/short names, values, combinations, and `NOFLAG` |
| `API-COMPILE` | `compile`, identity cache, `purge`, pattern metadata, str and bytes |
| `API-SEARCH` | module and compiled `search`, including `pos` and `endpos` |
| `API-MATCH` | module and compiled `match` |
| `API-FULLMATCH` | module and compiled `fullmatch` |
| `API-FINDALL` | zero, one, and multiple captures; empty and unmatched captures |
| `API-FINDITER` | ordered non-overlapping matches and empty-match advancement |
| `API-SPLIT` | captures, empty matches, and `maxsplit` |
| `API-SUB` | string/bytes templates, named/numeric groups, unmatched groups, callable, and `count` |
| `API-SUBN` | substituted value plus exact replacement count |
| `API-ESCAPE` | exact escaping for str and bytes |
| `API-PATTERN` | `pattern`, `flags`, `groups`, `groupindex`, copy/deepcopy/pickle, and all methods |
| `API-MATCH-OBJECT` | `group`, `groups`, `groupdict`, item access, `start/end/span`, `regs`, `lastindex/lastgroup`, `pos/endpos`, `re`, `string`, truth, and `expand` |
| `API-SCANNER` | compiled `scanner`, repeated `search`/`match`, and `.pattern` |
| `S-LITERAL` | ordinary, escaped, Unicode, and bytes literals |
| `S-DOT-CLASS` | `.`, ranges, negation, escaped class members, and class shorthands |
| `S-ANCHOR` | `^`, `$`, `\A`, `\Z`, `\z`, `\b`, and `\B` including final-newline behavior |
| `S-QUANTIFIER` | `*`, `+`, `?`, `{m}`, `{m,n}`, open bounds, greedy and lazy |
| `S-POSSESSIVE` | possessive quantifiers and their no-backtracking behavior |
| `S-ALTERNATION` | ordered `|` and concatenation precedence |
| `S-GROUP` | capturing, non-capturing, named, nested, and optional groups |
| `S-BACKREF` | numbered and named backreferences |
| `S-CONDITIONAL` | `(?(id/name)yes|no)` |
| `S-LOOKAROUND` | positive/negative lookahead and fixed-width lookbehind |
| `S-ATOMIC` | atomic groups and discarded backtracking points |
| `S-INLINE` | global/scoped inline flags and scoped flag removal |
| `S-VERBOSE` | whitespace, comments, and escaped whitespace under `VERBOSE` |
| `S-UNICODE` | Unicode digit/space/word classes and case folding |
| `S-ASCII` | ASCII class and case behavior for str and bytes |
| `S-LOCALE` | bytes `LOCALE` behavior in the deterministic `C` locale |
| `S-EMPTY` | empty patterns, zero-width results, and adjacency rules |
| `S-WINDOW` | compiled `pos`/`endpos` semantics without slicing the subject |
| `E-PATTERN` | invalid syntax and exact public `PatternError` fields |
| `E-TYPE` | mixed str/bytes and invalid public argument types |
| `E-TEMPLATE` | invalid replacement references and escapes |
| `E-WARNING` | documented ambiguous-set `FutureWarning` behavior |
| `E-DEBUG` | `DEBUG` is accepted and emits a non-empty disassembly stream |

The suite records each obligation on every case. It contains 80 directed cases, 768 seeded str differential cases, 384 seeded bytes differential cases, 384 algebraic/property cases, 240 invalid-pattern fuzz cases, and 192 invalid-template fuzz cases. Seeds are frozen in [seeds.json](seeds.json). The property cohort checks module/compiled equivalence, `findall` derived from `finditer`, `sub`/`subn`, replacement-count bounds, and `escape` round trips. The gate rejects missing mappings, duplicate IDs, non-deterministic fixture generation, interpreter drift, unexplained exceptions, and any mismatch.

A failing case has a stable ID and is reproduced without changing the denominator with `python tools/oracle.py verify --module <module> --case <case-id>`. Full failure records are written by `--output`; an empty `failures` array is still committed for the self-oracle.

Named private waivers:

1. `PRIVATE-CACHE-LAYOUT`: the private `_cache`, `_cache2`, eviction thresholds, and private compiler modules are not asserted. Public compile identity and `purge()` behavior are asserted.
2. `PRIVATE-DEBUG-TEXT`: exact opcode spelling and formatting of `DEBUG` output are implementation details. Accepting `DEBUG` and producing non-empty diagnostic output are asserted.
