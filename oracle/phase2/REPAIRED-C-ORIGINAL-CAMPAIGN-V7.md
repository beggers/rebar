# First-party C original correctness campaign, version 7

This experiment asks whether the project's own C regular-expression engine
matches Python 3.14.6 across every frozen original correctness test. It does
not wrap another regular-expression package. Its C source, Python adapter,
native extension, original test inputs, reference observations, and strict
anti-delegation guard are each independently identified by their complete
source and SHA-256.

Freezing, reading, checking, or rendering this protocol does not run the
candidate. Version 7 correctness, complete mismatch counts, runtime
independence, memory, speed, undefined behavior, candidate qualification, and
a winner are **NOT MEASURED** or **NOT ESTABLISHED** until an independently
pinned actual operation produces real evidence.
