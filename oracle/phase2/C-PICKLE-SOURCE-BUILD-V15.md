faster. It independently reconstructs all four already published version-28
results-graph owners. The current graph contains 145 real evidence files
and 150 authenticated references.

references; version 26 has 141 and 146; version 27 has 143 and 148. The

private C phases. Each uses one genuine copy of the unchanged

be byte-identical. Original C source and adapter files and active

External regular-expression packages, Python re, CPython's matching
engine, cross-candidate engines, approximations, and fallback are
forbidden. Synthetic checks physically block files, process creation,
imports, networking, and clocks. Source-context checks only authenticate
published evidence and never start a candidate or build.
